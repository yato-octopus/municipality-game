# 要件定義書：全国市区町村パズル＆地理学習ゲーム（v2.2.0）

## 1. 目的・対象定義

本システムは、React + TypeScript + 高精細ベクター白地図 SVG で構築する日本専門の地理学習ウェブアプリケーションである。

### 1.1 基本方針
1. **体系的な日本地理学習体験**: パズル・6択クイズ（下部表示／地図上ポインティング表示）・読み方・自然地理クイズ・閲覧・データ11タブ集計・間違えた問題の復習を統一された UI で提供する。
2. **精巧な日本白地図の採用**: 国土数値情報 N03-21（`smartnews-smri/japan-topography`, MIT/CC0）、OpenStreetMap（河川・湖沼）、国土地理院標高データ（DEM 等）に基づく高精細な白地図 SVG を採用し、47都道府県境・全国 1,747 市区町村境・全国 792 市・離島・北方領土・日本の自然地理 100 選を正確に表示する。
3. **ブラウザ完結型 SPA**: 外部バックエンドや課金・広告 SDK を持たず、純粋な学習・設定・共有体験に集中する。

## 3. 画面構成・機能一覧

### 3.1 タイトル画面 (`Title`)
- ゲームタイトル表示、**リリースバージョン表示**（タイトルバッジ横の `Release v2.2.0` ピルバッジおよびカード下部のバージョンフッター、`package.json` と同期）、**学習進捗サマリー**（都道府県クリア数・モード制覇数・ノーミス `★` 数・要復習件数）に加え、以下のメインメニュー項目を提供する：
  1. **ゲームをはじめる**: カテゴリ・エリア選択画面へ遷移。
  2. **前回のオートセーブから**: 直前のオートセーブが存在する場合、対象エリア名・モード名・問題進捗・経過時間・保存日時を表示して直接再開できるほか、2段階確認付きで破棄可能。
  3. **間違えた問題を復習**: 誤答履歴が存在する場合、モード別・まとめ復習モーダルを開く（削除・全消去は2段階確認付き）。
  4. **つづきから (`ManualContinue`)**: 手動保存されたセーブスロット一覧を表示し、任意のセーブデータから再開または2段階確認付きで削除する。
  5. **カスタム**:
     - 都道府県を地図・チェックリスト・地方ショートカット（全選択／部分選択ハイライト付き）から複数選択し、対象スコープとして **`選択県の市区町村`** / **`選択県の市のみ`** / **`選択都道府県そのもの`** を切り替え可能（0件選択時は開始無効化）。
     - スライダー・`±5` ボタン・プリセット（`10/20/50/全問`）で出題問題数を指定。
     - `パズル` / `クイズ` / `読み方` を選択して開始（※途中セーブ・クリア記録は残らないが、誤答はスコープ別 `modeId` で復習リストへ記録）。
  6. **ランダム (`Random`)**:
     - 日本のデータプール（`全国すべての市区町村` / `全国すべての市 (792)` / `都道府県 (47)` / `日本の自然地理100選`）から、スライダー・`±5`・プリセット（`10/20/50/全問`）で指定した問題数を出題する `パズル` / `クイズ` / `読み方` を開始（※途中セーブ・クリア記録は残らない）。
  7. **設定・更新履歴・出典 (`Other`)**:
     - 統一設定モーダル（`ConfigModal`）への起動導線に加え、**更新履歴 (`Ver 2.2.0` 先頭)**・**サウンド**・**描画負荷（標準・高／軽量）**・**オートセーブ**・**FPS設定**・**出典**・**クレジット**を表示。

### 3.3 地図・白地図表示要件 (`Precise Blank Map`)
1. **精巧な日本白地図**: 47都道府県・全 1,747 市区町村（うち 792 市）・自然地理 100 選のベクター輪郭を滑らかかつ精確に描画する。
2. **周辺都道府県コンテキスト＆低彩度の隣接県塗り分け**:
   - 単一都道府県や市専用マップをプレイ中でも、周囲の他都道府県・海岸線・非市エリアの白地図輪郭を低コントラストな背景コンテキストとして表示する。
   - **県当てモード（都道府県パズル／クイズ／読み方）以外のすべてのモード**（市区町村・市・県庁所在地・自然地理100選・閲覧モード）において、隣接する都道府県（海峡連絡含む）が同色にならない低彩度5色パレットで塗り分け、市区町村マップ上には鮮明な都道府県境オーバーレイを描画する。
3. **都道府県ホバーツールチップ**:
   - **県当てモード以外のすべてのモード**で、地図上の陸地にマウスカーソルを合わせると、現在指している都道府県名（`〇〇県`）をカーソル追従の軽量ツールチップで表示する（ドラッグパン中・海上・タッチ操作時は非表示）。
4. **離島インセット & ジャンプ**:
   - 北海道（北方領土含む）・東京（伊豆・小笠原）・鹿児島（奄美・トカラ）・沖縄等の離島が欠けず視認・操作できるよう適切なフレーミング／インセット配置を提供する。
5. **地図操作**:
   - Google マップのように、マウス左クリックドラッグ／タッチドラッグで地図を 1:1 にパン移動＋**慣性スクロール**（設定で慣性強度調整可能）。ピースドラッグ時の画面端オートスクロールは行わず、左クリックドラッグによる手動パン操作と共存させる。
   - ホイール・ピンチ・ダブルクリック・画面左側 **`Zoom` スライダー (`−`/`＋`)** による連続ズーム（ズーム中心座標維持）。
   - **地方移動ジャンプボタン (`JumpButton`)**: 日本・全市区町村・全国市プレイ時は `北海道・東北・関東・中部・近畿・中国・四国・九州・沖縄` へのワンタップ視点移動（設定「地方移動ボタンを逆に並べる」対応）。
6. **間違えた問題の記憶・復習機能**:
   - パズル・クイズ・読み方・地理クイズで誤答した問題（読み方モードの答え表示含む）をモード・地域ごとに `localStorage` へ自動保存する。
   - タイトル画面「間違えた問題を復習」、各エリアの `GameInfo` モーダル（「間違えた問題のみ挑戦」）、およびクリア直後のリザルト画面（「間違えた問題だけ復習する」）から、記憶した問題だけを出題する復習モードを起動できる。
   - 復習モードや通常プレイで対象問題をミスなく正解すると、自動的に復習リストから解除される。

### 3.4 共通ゲーム中 HUD・2段階ヒント・設定 (`Menu` & `Config`)
- **Ready 演出**: ゲーム開始直前に `Ready -> Go!` カウントダウンアニメーションを表示して計測開始。
- **上部 HUD**:
  - `スコア表示`: 経過時間 (`00:00:00.000` / 設定で非表示可)、ミス回数 (`Miss`)、**ヒント使用回数 (`ヒント`)**、進捗 (`クリア数/問題数`)。
  - **`🏷 回答後の名前: ON/OFF` ワンクリック切替ボタン**: プレイ中いつでも白地図上の配置済み・回答済み地名ラベル (`config.nameOnFix`) を即座に表示／非表示切替できる。
  - `Save`: 手動セーブスロット一覧を開き、新規保存・上書き保存・ロード・削除を実行（通常モードのみ; カスタム・ランダム時は無効化）。
  - `Menu (歯車)`: 設定モーダルを開く。
  - `Back`: 確認ポップアップなしで即座にマップ（エリア）選択画面へ戻る（通常モードは自動でオートセーブ保存。設定モーダルの「ホームへ」からはタイトル画面へ戻る）。
- **ヒント機能（パズルは2段階 `💡 ヒント1` / `💡 ヒント2`、クイズ・読み方は単一 `💡 ヒント`）**:
  - 下部の回答パネル（「場所へフォーカス」横、パズル時は下部トレイヘッダー）に配置する（設定「ヒントボタン無効化」で無効化可）。
  - **パズル（2段階ヒント・ズーム連動）**:
    - **`💡 ヒント1`（この辺サークル）**: 対象ピースと複数の隣接候補を包含する大きめの点線サークル（「ヒント1：この辺」）を地図上へ表示してその範囲へズームインする（再押下で表示／非表示トグル）。
    - **`💡 ヒント2`（そのまま当てはめ）**: 正解オブジェクトの位置へスムーズにズームインしつつ、地図上の正確な場所へ直接当てはめ・強調表示する。
  - **クイズ (`💡 ヒント`)**: 地図上に既に対象がハイライトされているためヒント1の円は設けず、押すたびに残っている誤答選択肢を2つずつ除外（6択→4択→2択→1択）する。自動正解にはしない。
  - **読み方 (`💡 ヒント` ＋ `答えを見る`)**: 地図上の円表示・ズームは行わず、頭文字1文字のみを表示する（解答表示は「答えを見る」に一本化）。
  - ヒントを使用するたびにヘッダーの `ヒント` 回数が加算される。
- **情報ウィンドウ (`Info`) & タグ (`MemoTagView`)**:
  - 対象ピース選択時・ドラッグ開始時・正解時に画面上部へ表示（設定「情報ウィンドウ」で ON/OFF 可）。
  - 表示内容：`ひらがな`・`漢字`・`ウィキペディア` リンク・`人口`・`地域(地方 / 行政地域 / 郡)`。
  - タグUI：初期タグ `面白い形` を含むカスタムタグの作成・ロック/ロック解除・名前変更・削除、ピースへのタグ付与、タグ別リスト (`DataTable2`) 閲覧。
- **詳細設定ダイアログ (`Config`)**:
  - 上段クイックボタン：`サウンド` (SE音量調整へ)・`ホーム`・`リトライ`
  - トグル項目：
    - `シルエット表示`（白地図シルエット / 簡易標高図調表示切替）
    - `時間表示`
    - `境界線`
    - `情報ウィンドウ`
    - `タグ表示`
    - `ヒントボタン無効化`
    - `ピースを表示`（パズルのピース一覧トレイ表示/非表示）
    - `地名の漢字表示`（読み方モード用）
    - `クイズ選択肢を地図上にポインティング表示`（クイズ選択肢レイアウト切替）
    - `地方移動ボタンを逆に並べる`
  - `完了時アクション`：`サウンド`（はめ込み・正解音 SE）・`バイブレーション`（Vibration API）
  - `名称表示`（3条件個別設定）：`リスト収納時` / `ドラッグ中` / `完了時（回答後に地図上へ名前表示）`
  - スライダー：`マップドラッグ慣性`

### 3.5 各プレイモード仕様
1. **パズル (`Puzzle`)**:
   - 下部スクロールリスト（トレイ）から未配置ピースをドラッグし、地図上の正解枠へ近づけるとハイライト＆スナップはめ込み。クリック／タップでの配置選択操作も補助サポート。
   - 不正解位置にドロップした場合は元のトレイへ戻り `Miss` 加算。
   - 正解時はピコン／鐘SE・バイブレーション・進捗更新・完了時名称表示判定。
2. **クイズ (`Quiz` - 6択)**:
   - 問題ごとに地図上の1ピースが点滅／強調色表示（自動で該当ピースへカメラフォーカス）。
   - **選択肢レイアウト2方式（ワンクリック切替対応）**:
     - **下部パネル表示 (`bottom`)**: 下部グリッドに6個の選択肢カード（ルビ・漢字、同名ピース重複防止）を表示。
     - **地図上ポインティング表示 (`pointing`・デフォルト)**: 地図上の対象位置（河川では川線上の最近点）にアンカー点を打ち、対象を覆わず・カード同士が重ならず・画面内へ収まる位置へ6枚のフローティング選択肢カードとリーダー線を描画する。パン・ズーム・リサイズにリアルタイム追従し、下部操作バーをスリム化して地図の視認性を最大化する。
   - 正解で `○ (maru)` エフェクト＆次問へ進行。不正解で `× (batu)` エフェクト・ボタン無効化（同誤答の連打防止）・ミス加算。
   - クリア済みピースの地図上名称表示をヘッダーから即座に切り替え可能。
3. **読み方 (`Yomikata`)**:
   - 地図上ハイライト＋対象漢字名と文字数ヒント表示（「地名の漢字表示」チェック解除で非表示練習可）。
   - キーボード入力前提のテキストボックス（自動フォーカス・日本語 IME 変換確定対応）にひらがな／カタカナで入力し、Enter キーで正誤判定して連続的に次の問題へ進行する。答え表示（ミス記録）や場所フォーカス・2段階ヒントボタンも下部回答欄に配置する。
4. **地理クイズ (`GeographyQuiz`)**:
   - **県庁所在地クイズ / 県庁所在地読み方**: 都道府県（または県庁位置）をハイライトし、県庁所在地を6択（下部／ポインティング対応）またはキーボード入力で解答。
   - **地形クイズ (`主な山脈、山地、高地` / `主な山` / `主な河川` / `主な平野` / `主な湖`)**:
     - `TextWindow` に解説ヒントを表示（固有名やヒント表現付き）。
     - 地図上に実測データに基づく地形ポリゴン（山・平野・湖沼）やライン（山脈帯・河川流路）をハイライト表示し、6択（下部／地図上ポインティング表示）から名称を解答。

### 3.6 クリア結果画面 (`Result`)
- 全問達成時に紙吹雪パーティクル (`Complete`) を表示後、リザルトカードを表示。
- 表示項目：モード・エリアタイトル、クリアタイム、`NewRecord` バッジ（最大問題数かつ最速更新時）、ミス数、星評価、問題数、今回間違えた問題一覧。
- アクション：
  - `リトライ`: カスタム／ランダムモード時は「同じ場所でリトライ」「ランダムでリトライ」の両選択肢を提示。通常モードは即リトライ確認。
  - `間違えた問題だけ復習する`: 誤答があった場合にそのまま復習モードを起動。
  - `タイトル`: タイトル画面へ戻る。
