# 要件定義書：全国市区町村パズル＆地理学習ゲーム

## 1. 目的・対象定義

本システムは、React + TypeScript + 高精細ベクター白地図 SVG で構築する日本および世界の地理学習ウェブアプリケーションである。

### 1.1 基本方針
1. **体系的な地理学習体験**: パズル・6択クイズ・読み方・自然地理クイズ・閲覧・データ集計・間違えた問題の復習を統一された UI で提供する。
2. **精巧な白地図の採用**: 国土地理院／国土数値情報ベースのオープンデータ（MIT/CC0）および Natural Earth（ISC/Public Domain）に基づく高精細な白地図 SVG を採用し、都道府県境・全国 1,747 市区町村境・離島・北方領土・世界 284 国地域を正確に表示する。
3. **ブラウザ完結型 SPA**: 外部バックエンドや課金・広告 SDK を持たず、純粋な学習・設定・共有体験に集中する。

## 3. 画面構成・機能一覧

### 3.1 タイトル画面 (`Title`)
- ゲームタイトル表示および以下のメインメニュー項目を提供する：
  1. **ゲームをはじめる**: カテゴリ・エリア選択画面へ遷移。
  2. **前回のオートセーブから**: 直前のオートセーブが存在する場合、対象エリア名・モード名・問題進捗を表示し、直接ゲームを再開する。
  3. **つづきから (`ManualContinue`)**: 手動保存されたセーブスロット一覧を表示し、任意のセーブデータから再開または削除する。
  4. **カスタム (`Training2`)**:
     - 都道府県を地図またはチェックリストから複数選択（例：埼玉＋千葉＋東京等）または全国/単県から任意問題数を設定。
     - スライダー・`−`/`＋`ボタンで出題問題数を指定。
     - `パズル` / `クイズ` / `読み方` を選択して開始（※途中セーブは残らない）。
  5. **ランダム (`Random`)**:
     - 全国のエリア（都道府県・市区町村・世界等のデータプール）から、指定した問題数（スライダー/`−`/`＋`）を出題する `パズル` / `クイズ` / `読み方` を開始（※途中セーブは残らない）。
  6. **その他 (`Other`)**:
     - **更新履歴 (`ChangeLog`)**: Ver 3.0.0 〜 Ver 4.1.0 の変更履歴一覧。
     - **サウンド設定 (`Sound`)**: SE音量スライダー。
     - **画質設定 (`Quality`)**: 高画質・標準・軽量等の描画負荷/線精度設定。
     - **オートセーブ設定 (`AutoSave`)**:
       - `正解ごとにセーブする`（不意終了耐性あり）
       - `タイトルにもどる、他のアプリに切り替える時にセーブする`（正解時負荷軽減）
     - **FPS設定 (`FPS`)**: `FPSを高くする` (60fps) / `FPSを低くする` (30fps)。
     - **出典 (`Source`)**: 人口・選挙投票率・面積データの公式出典明記。
     - **クレジット (`Credit`)**: 国土地理院「白地図」「自分で作る色別標高図」加工クレジットおよび使用ライブラリの OSS ライセンス表示。

### 3.3 地図・白地図表示要件 (`Precise Blank Map`)
1. **精巧な白地図**: 全都道府県・全 1,747 市区町村・世界 284 国地域のベクター輪郭を滑らかかつ精確に描画する。
2. **周辺都道府県コンテキスト表示**: 単一都道府県をプレイ中でも、周囲の他都道府県・海岸線の白地図輪郭を背景として表示する（Ver 4.0.0 仕様）。
3. **離島インセット & ジャンプ**: 北海道（北方領土含む）・東京（伊豆・小笠原）・鹿児島（奄美・トカラ）・沖縄等の離島が欠けず視認・操作できるよう適切なフレーミング／インセット配置を提供する。
4. **地図操作**:
   - Google マップのように、マウス左クリックドラッグ／タッチドラッグで地図を 1:1 にパン移動＋**慣性スクロール**（設定で慣性強度調整可能）。ピースドラッグ時の画面端オートスクロールは行わず、左クリックドラッグによる手動パン操作と共存させる。
   - ホイール・ピンチ・ダブルクリック・画面左側 **`Zoom` スライダー (`−`/`＋`)** による連続ズーム（ズーム中心座標維持）。
   - **地方移動ジャンプボタン (`JumpButton`)**: 日本/全市区町村プレイ時は `北海道・東北・関東・中部・近畿・中国・四国・九州・沖縄` へのワンタップ視点移動（設定「地方移動ボタンを逆に並べる」対応）、世界プレイ時は `ヨーロッパ・アフリカ・中東・アジア・オセアニア・アメリカ` への視点移動。
5. **間違えた問題の記憶・復習機能**:
   - パズル・クイズ・読み方・地理クイズで誤答した問題（読み方モードの答え表示含む）をモード・地域ごとに `localStorage` へ自動保存する。
   - タイトル画面「間違えた問題を復習」、各エリアの `GameInfo` モーダル（「間違えた問題のみ挑戦」）、およびクリア直後のリザルト画面（「間違えた問題だけ復習する」）から、記憶した問題だけを出題する復習モードを起動できる。
   - 復習モードや通常プレイで対象問題をミスなく正解すると、自動的に復習リストから解除される。

### 3.5 各プレイモード仕様
1. **パズル (`Puzzle`)**:
   - 下部スクロールリスト（トレイ）から未配置ピースをドラッグし、地図上の正解枠へ近づけるとハイライト＆スナップはめ込み。クリック／タップでの配置選択操作も補助サポート。
   - 不正解位置にドロップした場合は元のトレイへ戻り `Miss` 加算。
   - 正解時はピコン／鐘SE・バイブレーション・進捗更新・完了時名称表示判定。
2. **クイズ (`Quiz` - 6択)**:
   - 問題ごとに地図上の1ピースが点滅／強調色表示（自動で該当ピースへカメラフォーカス）。
   - 下部の 6個の選択肢カード（ルビ・漢字、同音・類似地名等も考慮し同名ピースが複数候補に出ない制御・Ver 3.5.3「泊村」重複対策含む）から正解をタップ。
   - 正解で `○ (maru)` エフェクト＆次問へ進行。不正解で `× (batu)` エフェクト・ボタン無効化（同誤答の連打防止・Ver 3.4.0仕様）・ミス加算。
   - クリア済みピースの地図上名称表示を切り替え可能（Ver 3.1.0仕様）。
3. **読み方 (`Yomikata`)**:
   - 地図上ハイライト＋中央上部の漢字名表示（「地名の漢字表示」チェック解除で非表示練習可）。
   - ひらがな回答枠に、画面下部の専用ソフトウェアキーボードで文字入力：
     - **`五十音` モード**: あ行〜わ行 50キー配列（や・ゆ・よ間空白、わ・を・ん・`゛゜大小` キー）＋バックスペース。
     - **`フリック` (Swipe) モード**: 12キー配列（あかさたなはまやらわ・`゛゜大小`・空白/削除）。ボタン押下後の上下左右フリック／タップ入力対応。
   - 全文字入力（または文字一致）時に正誤判定し、正解なら次問へ遷移。パス/ヘルプ可。
4. **地理クイズ (`GeographyQuiz`)**:
   - **県庁所在地クイズ / 県庁所在地読み方**: 都道府県（または県庁位置）をハイライトし、県庁所在地を6択または五十音/フリックで解答。
   - **地形クイズ (`主な山脈、山地、高地` / `主な山` / `主な河川` / `主な平野` / `主な湖`)**:
     - `TextWindow` に解説ヒントを表示（固有名やヒント表現付き）。
     - 地図上に該当する地形ポリゴン（三角山マーク・湖沼ポリゴン）やライン（山脈帯・河川流路・平野円）をハイライト表示し、6択から名称を解答。

### 3.6 クリア結果画面 (`Result`)
- 全問達成時に紙吹雪パーティクル (`Complete`) を表示後、リザルトカードを表示。
- 表示項目：モード・エリアタイトル、クリアタイム、`NewRecord` バッジ（最大問題数かつ最速更新時）、ミス数、星評価、問題数。
- アクション：
  - `リトライ`: カスタム／ランダムモード時は「同じ場所でリトライ」「ランダムでリトライ」の両選択肢を提示。通常モードは即リトライ確認。
  - `タイトル`: タイトル画面へ戻る。
  - `完成図をみる`: リザルトUIを一時隠して完成した白地図を自由ズーム・閲覧・情報確認できるモードへ移行（戻るボタンでリザルト復帰）。
  - `記録をシェアする`: `{エリア名} を {タイム} でクリア！ #市区町村パズル #市町村パズル #世界パズル` テキストを共有（Web Share / クリップボードコピー）。

### 3.7 閲覧モード (`ViewMode`) & データテーブル (`DataTable`)
#### 閲覧モード (`ViewMode`)
- ゲーム時間制限なしで日本（都道府県／全市区町村）・各都道府県・世界を精巧な白地図上で自由閲覧。
- 地図上の任意のピースをクリック／タップで `Info` ウィンドウ＆タグ操作が開く。
- 専用操作バー／パネル：
  - `エリア選択` (`日本` / `市町村` / `世界` / 47都道府県)
  - `境界線有り` / `境界線なし`
  - `シルエット` / `標高図`（単色白地図スタイルと色別標高図スタイルの切替）
  - `名前あり` / `名前なし`
  - `県庁マークあり` / `県庁なし`（県庁所在地ピン・マーク表示切替）
  - `県庁←→都道府県`（都道府県ラベルと県庁所在地ラベルの切替）
  - `データ` (`DataTable` を開く)
  - `タイトルへ`

#### データ一覧画面 (`DataTable` 全12タブ ＋ `SubTable` ＋ `地域` ＋ `検索`)
- 閲覧中または選択中エリア（日本全体／全国市区町村／各都道府県／世界）のデータに対し、上部 12個のタブで分類・集計・並び替え表示を行う：
  1. `市町村`（自治体コード順一覧）
  2. `50音`（読み仮名50音順＋行ジャンプ）
  3. `人口`（人口降順・総計比較）
  4. `面積`（面積降順・総計比較）
  5. `漢字`（自治体名に使われている漢字の出現自治体数ランキング ＋ 行クリックで `SubTable` に該当漢字を含む全自治体を表示）
  6. `ひらカナ`（ひらがな・カタカナを含む市町村名一覧：`あきる野市`, `さいたま市`, `ニセコ町`, `南アルプス市` 等 ＋ 分類集計）
  7. `文字数`（自治体名の文字数別グループ集計 ＋ クリックで `SubTable` に一覧表示）
  8. `選挙投票率`（令和元年参院選投票率降順 — 都道府県一覧等）
  9. `似た名前`（読み・漢字が同一または紛らわしい自治体グループ：`鹿嶋・鹿島・嘉島`, `柏・柏原・橿原`, `利島・十島・豊島` 等の一覧 ＋ `SubTable` でマップ確認）
  10. `まち・ちょう`（全町名の「〜まち」「〜ちょう」読み比率・都道府県別統計 ＋ `SubTable`）
  11. `むら・そん`（全村名の「〜むら」「〜そん」読み比率・都道府県別統計 ＋ `SubTable`）
  12. `市町村区`（市・町・村・特別区の件数・構成比率集計 ＋ `SubTable`）
- 検索入力欄 (`検索`) による漢字・ふりがなインクリメンタル検索。
- 地域フィルター (`地域`: `市町村` / `地方` / `地域区分` / `郡`) により特定地方・特定郡のみの絞り込み・サブ一覧表示に対応。
- テーブル項目クリックで該当ピースの地図フォーカス・`Info`・Wikipedia表示が可能。

## 4. 非機能要件・品質基準

1. **ビルド・型安全性**: TypeScript strict モード (`noUnusedLocals`, `noUnusedParameters`, `erasableSyntaxOnly`, `verbatimModuleSyntax`) の下、`tsc -b && vite build` および `eslint .` がエラー・警告ゼロで通過すること。
2. **描画パフォーマンス**: 全国 1,747 市区町村を同時描画するモードでもズーム・パンが滑らかに動作すること（トポロジー簡素化済みパス、React メモ化、不要な再計算抑制）。
3. **永続化**: オートセーブ・手動セーブ・記録（ベストタイム・ノーミス・クリア数）・間違えた問題の履歴・タグ・詳細設定をすべて `localStorage` に永続化すること。
