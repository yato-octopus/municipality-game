# 設計書：全国市区町村パズル＆地理クイズ アーキテクチャ設計

## 1. システム全体構成

## 2. 白地図データ生成・座標設計 (`scripts/build_map_data.py`)

### 2.1 日本・市区町村データのトポロジー統合
1. **ソース**: 国土数値情報行政区域 N03-21 (`smartnews-smri/japan-topography` `s0010/N03-21_210101.json` および `prefectures.json`、MIT/CC0)。
2. **政令指定都市の区マージ**:
   - N03-21 は政令指定都市が行政区単位（例：`01101`〜`01110`）で分割されている一方、本アプリでは指定都市を1つの市ピース（例：`01100 札幌市`）として扱う。
   - Python ジェネレータで TopoJSON のアーク参照配列を走査し、同一指定都市内の区が双方向で共有する内部境界アークを除去し、外周アークのみを連結して 20 指定都市のシームレスな統合ポリゴンを生成する。
   - 平成30年市制施行によりコード変更された福岡県那珂川市 (`40231` ⇔ 旧 CSV `40305`) をコードマッピングし、全 1,747 市区町村（北方領土6村 `01695`〜`01700` 含む）を欠損ゼロで接続する。
3. **投影法・インセット配置**:
   - **全国日本地図ビュー**（`viewBox: 0 0 1000 1000`）：メルカトル投影で本州・北海道・九州・四国・北方領土を中央配置し、南西諸島（沖縄本島・先島諸島・大東諸島）を見やすい左下/左上枠（枠線付きインセット）に収める標準白地図レイアウト、かつ沖縄県単体モード時は実位置比率で全諸島を描画。
   - **東京都ビュー**（`13_tokyo`）：本土部に加え伊豆諸島・小笠原諸島を別インセットまたは全体視野に配置し、`島しょ部` 単独プレイ時は島しょ部中心にフレーミングする。
   - **自然地理100件座標変換**:
     - 主要ランドマーク座標と日本白地図上の実重心 `(sx, sy)` とのアフィン変換を算出し、`geography_100.json` 内の山(21)・山脈(24)・川(16)・平野(17)・湖(22) の全頂点を SVG 座標系へ高精度写像する。

### 2.2 世界地図データ (`world_map.json`)
- **ソース**: Natural Earth 1:10m (`ne_10m_admin_0_map_subunits`, `ne_10m_admin_0_disputed_areas`, `ne_10m_minor_islands`, Public Domain) を Ramer-Douglas-Peucker 適応簡素化（大面積国は滑らかに、小島嶼は 1:10m 原形状を保持）して生成（`scripts/rebuild_world_map_10m.py`）。
- 離島・飛び地・係争地域（アラスカ、ハワイ、カリーニングラード、スヴァールバル諸島、カナリア諸島、アゾレス諸島、マデイラ諸島、ガラパゴス諸島、イースター島、レユニオン、グアドループ、マルティニーク、マヨット、クリミア、北方領土、尖閣諸島、竹島、ボネール／サバ／シント・ユースタティウス、グレナディーン諸島等）を含め、全 **284件** を円マーカーではなく実形状ポリゴンで描画し、極小島には非表示の透明ヒット判定領域のみを付与して操作性を確保する。

## 3. コンポーネント＆状態遷移設計

### 3.1 コア状態管理 (`App.tsx`)
`AppView` は以下の単純明快なユニオン型で管理し、画面遷移の不整合を防ぐ：
- `title`: タイトル画面＋サブモーダル（エリア選択 `Game/Game2`、`GameInfo`、手動ロード、`カスタム`、`ランダム`、`その他`）
- `play`: アクティブなプレイセッション（`puzzle` | `quiz` | `yomikata` | `geography_quiz`）
- `view`: 閲覧モード（＋ `DataTable`）

### 3.2 パズルのドラッグ＆スナップ設計
- **ドラッグ処理**: Pointer Events (`onPointerDown` / `onPointerMove` / `onPointerUp` + `setPointerCapture`) を使用し、マウス・トラックパッド・タッチに統一対応。
- **ドラッグ中UI**:
  - 下部トレイからドラッグ開始したピースの実寸シルエットをポインタ上部に追従描画し、設定 `名称表示 > ドラッグ中` に応じて地名ラベルを表示。
  - ピースドラッグ中に地図の自動スクロールは発動せず、マップ移動は Google マップ同様の左クリックドラッグ／ホイールズームで自由に行える。
  - ポインタ位置を地図SVG座標へ逆変換し、正解ピースのポリゴン包含判定（`data-piece-id`）または基準重心との距離（スクリーン換算しきい値 px）を満たした状態でドロップすると正解判定。

### 3.3 ビューポート・慣性・標高図カラーリング
- **白地図モード (`silhouette: true`)**: 土地＝純白寄りのオフホワイト (`#FAF9F5`)、海＝淡い地図青 (`#DFECFA`)、未回答枠＝薄い白灰 (`#EFECE4`)、境界線＝鮮明な細線 (`#475569`)。
- **標高図モード (`silhouette: false` — 閲覧モード & Config 切替)**: 都道府県／土地ごとの擬似標高グラデーション（国土地理院「色別標高図」の雰囲気を再現する緑〜黄土〜茶系の落ち着いた自然地理パレット：各ピースの面積・緯度・地域特性に応じた SVG グラデーション／着色）で切り替わる。
- **周辺都道府県表示**: 単一都道府県・北海道地方分割プレイ時でも、`japan_prefs.json` の全 47都道府県パスを背景層（半透明白地図・境界線付き）として必ず同時レンダリングする。

### 3.4 読み方キーボード入力設計 (`YomikataGame.tsx`)
- 画面下部のテキスト入力欄へ出題ごとに自動フォーカスし、キーボードだけで連続解答できる設計とする。
- `onCompositionStart` / `onCompositionEnd` により日本語 IME の変換確定を正確に判定し、IME 確定時に入力値が正解と一致した場合は即座に正解・次問へ遷移する。
- 非変換時の Enter キーで正誤判定し、誤答時は赤フィードバック＋入力テキスト全選択として即座に打ち直せるようにする。空文字での Enter は誤爆ミス防止のため無視する。

### 3.5 DataTable 11タブ解析エンジン (`dataAnalyzer.ts`)
- 各タブのロジック：
  1. `市町村`: `code` 昇順。
  2. `50音`: `reading` 昇順 (`localeCompare('ja')`)。
  3. `人口`: `population` 降順（北方領土等0人は末尾）。
  4. `面積`: `areaKm2` 降順。
  5. `漢字`: 対象エリア内の全団体名から一文字ずつ漢字 (`[\u4E00-\u9FFF\u3400-\u4DBF々]`) を抽出し、使用回数の多い順に集計（例：「山」「川」「島」「田」等）。タップで該当漢字を含む団体リストを `SubTable` 表示。
  6. `ひらカナ`: 団体名にひらがな（`\u3041-\u3096`）またはカタカナ（`\u30A1-\u30F6ー`）が含まれる団体を抽出し、「ひらがな」「カタカナ」「混在」別および団体一覧で表示。
  7. `文字数`: 漢字表記文字数（例：2文字〜7文字）ごとに件数集計し、クリックで該当団体を `SubTable` 表示。
  8. `似た名前`: 同名・同音・類似地名辞書（`芦屋`, `鹿嶋/鹿島/嘉島`, `橿原/柏原/柏`, `府中`, `伊達`, `泊` 等約120グループ）を表示し、グループクリックで所属自治体を `SubTable` 表示＋地図上比較確認可能。
  9. `まち・ちょう`: 「〜町」の読み末尾（`まち` vs `ちょう` vs その他）の全件数比率および都道府県別分布。クリックで詳細一覧表示。
  10. `むら・そん`: 「〜村」の読み末尾（`むら` vs `そん`）の全件数比率および都道府県別分布。
  11. `市町村区`: `市` / `町` / `村` / `区` の件数・割合集計＋一覧。

## 4. セキュリティ・アクセシビリティ・テスト計画

- 外部通信は Wikipedia 外部リンク（`rel="noopener noreferrer"`、新規タブ）および任意シェアリンクのみとし、ユーザーデータはローカル保存に限定する。
- 全自動検証として、以下を完了時に実行する：
  1. **データ整合性検証スクリプト**: 47都道府県、1,747市区町村、284世界地域、100自然地理データの ID・SVGパス存在・座標範囲（NaN/空パス 0件）を検証。
  2. **型・ビルド・Lint 検証**: `npm run build` (`tsc -b && vite build`) および `npm run lint` (`eslint .`) が 0 errors で通ること。
  3. **UI・描画実機確認**: Vite ローカルプレビューを起動し、タイトル画面・白地図表示（全国日本・東京・世界）・パズル・クイズ・読み方・閲覧/データ11タブ・設定がエラーなく表示・操作できることを確認する。
