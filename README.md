# 全国市区町村パズル＆地理クイズ（白地図版） `v2.2.0`

日本47都道府県・全国1,747市区町村（北方領土6村・政令指定都市対応）・全国792市・日本の自然地理100選（山脈・山・河川・平野・湖）を、高精細ベクター白地図 SVG 上で体系的に学習できる日本専門の地理学習 Web アプリケーションです。

## 主な機能（v2.2.0）
- **4つの学習カテゴリ＆全国「市」専用マップ**
  - **日本**: 47都道府県（パズル / 6択クイズ / 読み方）、県庁所在地（クイズ / 読み方）、日本の自然地理100選（主な山脈・山地・高地 / 主な山 / 主な河川 / 主な平野 / 主な湖）を直接カードから選択可能
  - **都道府県別（47都道府県）**: 検索・状態フィルタ（すべて／未クリア／復習あり）・8地方見出しで素早くアクセス（北海道の道央・道南・道北・道東分割、東京都の23区・多摩・島しょ部パズル／クイズ／読み方に対応）
  - **全国・地方別 市区町村**: 全国1,747市区町村および7地方別
  - **全国・地方別 市**: 全国792市・北海道の市・7地方別の市専用マップ（非市エリアは低コントラストの周辺地形コンテキストとして表示し、非市ラベルを抑制）
- **クイズ地図上ポインティング選択肢モード（デフォルト）＆キーボード操作**
  - 6択クイズ・地理クイズで、地図上ポインティング選択肢表示をデフォルトとし、下部パネル表示ともワンクリック切替可能
  - 対象位置（河川は川線上の最近点）へリーダー線とアンカー点を結び、モバイル・狭幅画面では上下3+3配置へ自動切替して対象を覆わず表示
  - `1`〜`6` キー回答、`H`（ヒント）、`F`（フォーカス）、`L`（配置切替）のキーボードショートカット対応
- **パズル快適操作＆2段階ヒント**
  - トレイ検索・並び替え（シャッフル／50音／都道府県／面積）、未配置ピースのネタバレ防止、軽量 DOM ドラッグ追従、トレイ非表示時の単一ピース出題プロンプトに対応
  - **パズル（2段階ヒント・ズーム連動）**: **💡 範囲ヒント**で複数候補を含む「この辺」サークルを表示＆ズーム（再押下で表示／非表示切替）、**🎯 答えをはめる**で正解位置へズーム＆直接配置
  - **クイズ**: **ヒント**で誤答選択肢を2つずつ除外（答え確認ボタンも併用可）
  - **読み方**: 日本語 IME 変換確定誤爆防止（Safari 対応）・都府県サフィックス柔軟判定・2段階ヒント・全表示「答えを見る」に対応
  - 厳密な初回正答率・星評価・ノーミス王冠判定と、進捗バー・消音トグル付き上部 HUD
- **高精細白地図・地名衝突回避・直感的な操作**
  - 共有アーク位相一致ベクター境界（0.001単位精度）、画面ピクセル基準の地名ラベル衝突回避＆スケーリング、パン境界クランプ、カーソル中心ズーム、最大120倍拡大＆日本全体縮小に対応
  - 県当て以外の全モードで低彩度5色隣接県塗り分け・県境オーバーレイ・都道府県ホバーツールチップを表示
  - 回答後の地図上名前表示トグル（ON/OFF）、完了図の誤答箇所ハイライト（黄枠）確認に対応
- **白地図閲覧モード（自然地理100選アトラス対応）＆データ11タブ集計**
  - 47都道府県・全市区町村・全国市に加え、**日本の自然地理100選**を地図上で自由閲覧。クイック地名検索（`/`）、ズームスライダー＆倍率表示、`+`/`-`/`0` ショートカット、「このエリアで挑戦」・タグ練習ショートカットを搭載
  - 11タブ集計（コード／50音／人口／面積／漢字／ひらカナ／文字数／似た名前／まち・ちょう／むら・そん／市町村区）＋昇降順切替＋増分表示＋カタカナ対応検索＋大量チップ絞り込み＋行クリックで地図フォーカス移動
- **オートセーブ / 手動セーブ / カスタム / ランダム / 復習 / タグ / 統一設定**
  - ホーム画面の学習進捗サマリー（クリア数・ノーミス `★`・要復習件数）、モード別＆まとめ復習、全モーダル `Esc` 閉じ対応、削除・上書き・リトライの2段階確認、ホーム／ゲーム共通の統一設定ダイアログ（描画負荷「軽量」切替対応）
- **リリースバージョン表示**
  - ホーム画面に現在のリリースバージョン（`v2.2.0`）を表示

## ローカル起動
```bash
npm install
npm run dev
```

## ビルド
```bash
npm run build
```

## GitHub Pages への公開
`main` ブランチへ push すると `.github/workflows/deploy-pages.yml` が自動実行され、`dist/` が GitHub Pages へデプロイされます。
GitHub リポジトリの **Settings > Pages > Build and deployment > Source** を **GitHub Actions** に設定してください。
