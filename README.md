# 全国市区町村パズル＆地理クイズ（白地図版）

日本47都道府県・全国1,747市区町村（北方領土6村含む）・日本の自然地理100選・世界284国地域を、高精細ベクター白地図 SVG 上で学習できる Web アプリケーションです。

## 主な機能
- **パズル / クイズ（6択） / 読み方（五十音・フリック） / 自然地理クイズ**
- **間違えた問題の自動記憶＆復習モード**（モード別復習・市区町村まとめ復習・正解時の自動解除）
- **Googleマップ風の左クリックドラッグパン＆ホイール／ダブルクリックズーム**
- **白地図閲覧モード＆データ12タブ集計**（コード順・50音・人口・面積・漢字・ひらカナ・文字数・選挙投票率・似た名前・まち/ちょう・むら/そん・市町村区）
- **オートセーブ / 手動セーブ / カスタム / ランダム / タグ管理**

## ローカル起動
```bash
npm install
npm run dev
```

## ビルド
```bash
npm run build
```

## GitHub Pages への公開
`main` ブランチへ push すると `.github/workflows/deploy-pages.yml` が自動実行され、`dist/` が GitHub Pages へデプロイされます。
GitHub リポジトリの **Settings > Pages > Build and deployment > Source** を **GitHub Actions** に設定してください。
