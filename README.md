# 全国市区町村パズル＆地理クイズ（白地図版） `v2.0.1`

日本47都道府県・全国1,747市区町村（北方領土6村・政令指定都市対応）・全国792市・日本の自然地理100選（山脈・山・河川・平野・湖）を、高精細ベクター白地図 SVG 上で体系的に学習できる日本専門の地理学習 Web アプリケーションです。

## 主な機能（v2.0.1）
- **4つの学習カテゴリ＆全国「市」専用マップ**
  - **日本**: 47都道府県（パズル / 6択クイズ / 読み方）、県庁所在地（クイズ / 読み方）、日本の自然地理100選（主な山脈・山地・高地 / 主な山 / 主な河川 / 主な平野 / 主な湖）
  - **都道府県別（47都道府県）**: 各都道府県の市区町村（北海道の道央・道南・道北・道東分割、東京都の23区・多摩・島しょ部分割に対応）
  - **全国・地方別 市町村**: 全国1,747市区町村および7地方別
  - **全国・地方別 市**: 全国792市・北海道の市・7地方別の市専用マップ（非市エリアは低コントラストの周辺地形コンテキストとして表示）
- **クイズ地図上ポインティング選択肢モード（デフォルト）**
  - 6択クイズ・地理クイズで、地図上ポインティング選択肢表示をデフォルトとし、下部パネル表示ともワンクリック切替可能
  - 対象位置（河川は川線上の最近点）へリーダー線とアンカー点を結び、対象や他カードと重ならず画面内に収まるようパン・ズームへリアルタイム追従
- **ヒント機能＆ヘッダー回数表示**
  - **パズル（2段階ヒント・ズーム連動）**: **ヒント1**で複数の隣接候補を含む大きめの「この辺」サークルを表示＆ズームイン（再押下で表示／非表示切替）、**ヒント2**で正解オブジェクトの位置へズームインしながら地図上へ直接当てはめ
  - **クイズ**: **ヒント**を押すたびに誤答選択肢を2つずつ除外（自動正解にはせず、自分で回答可能）
  - **読み方**: **ヒント**で頭文字1文字のみ表示（解答確認は「答えを見る」に統一）
  - ヘッダーの `ヒント` カウンタで使用回数をリアルタイム表示
- **都道府県ホバーツールチップ＆低彩度の隣接県塗り分け**
  - 県当て以外の全モード（市区町村・市・県庁所在地・自然地理100選・閲覧モード）で、隣接する都道府県が同色にならない低彩度5色パレット塗り分け・鮮明な県境線・カーソル追従の都道府県名ツールチップ（`〇〇県`）を表示
- **ヘッダーからの回答後地名表示切替**
  - プレイ中いつでもヘッダーの `🏷 回答後の名前: ON/OFF` ボタンで、配置済み・回答済みピースの地図上ラベル表示を即座に切替可能
- **読み方キーボード連続入力＆間違えた問題の復習モード**
  - 日本語 IME 対応キーボード入力＋Enter 連続回答
  - 誤答問題の自動記憶・モード別／まとめ復習・ノーミス正解時の自動解除
- **Google マップ風の直感的な地図操作**
  - 左クリックドラッグによるパン＆慣性スクロール、ホイール／ピンチ／ダブルクリック／スライダーによる連続ズーム、地方ジャンプボタン
- **白地図閲覧モード＆データ11タブ集計**
  - コード順・50音・人口・面積・漢字・ひらカナ・文字数・似た名前・まち/ちょう・むら/そん・市町村区の11タブ解析と検索・地域フィルタ
- **オートセーブ / 手動セーブ / カスタム / ランダム / タグ管理**
  - カスタム（選択県の市区町村・選択県の市のみ・選択都道府県）・ランダム（全市区町村・全国すべての市・都道府県・自然地理100選）に対応
- **リリースバージョン表示**
  - ホーム画面に現在のリリースバージョン（`v2.0.1`）を表示

## ローカル起動
```bash
npm install
npm run dev
```

## ビルド
```bash
npm run build
```

## GitHub Pages への公開
`main` ブランチへ push すると `.github/workflows/deploy-pages.yml` が自動実行され、`dist/` が GitHub Pages へデプロイされます。
GitHub リポジトリの **Settings > Pages > Build and deployment > Source** を **GitHub Actions** に設定してください。
